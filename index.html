01 — AI research terminal · Flagship

finplatform — research that tells you the truth

An AI financial research terminal: one place to screen stocks, price options, research private companies, and pressure-test your own ideas.

5→1apps consolidated into one terminal
16backtest configurations, reported honestly
local → Claudetiered model router, pick honored end-to-end
4behavior invariants under continuous eval

Every request rides a tiered router — from a local model on my own GPU up to Claude — and the model you pick is honored by every feature, with credits metered per model. Nothing is hidden behind a vague “AI” label: the interface tells you which model answered and what it cost.

The surfaces: a metric-driven screener where adding one metric definition buys filter, sort, and column for free; an options clarity panel on live chains — expected move, move needed, odds; a private-company research pipeline with a market map; auth with server-side JWT verification.

Under it all is an honesty layer: a custom test harness and an LLM behavior eval that holds every answer to four invariants — no fabrication, injection resistance, honest caveats, and abstention when the data isn’t there.

Honest verdict

A 16-configuration swing-trade backtest found no significant edge. finplatform reports that plainly — the product’s job is truth, not comfort.

Python (stdlib backend) · React + Vite · Ollama→Claude router · Supabase

02 — Translation workspace

Passage — translation that shows its work

A translation workspace for text, documents, images, and voice — with a human in the review loop, segment by segment.

96.86%cost reduction vs agency translation
57tests gating every deploy
4input modes: text, document, image, voice
0silent failures — it raises, never fakes

Passage doesn’t hand you a wall of translated text and hope. It shows every segment side by side with its source so you can review, refine, and trust the result. Photograph a sign and it composites the translation back onto the image. Speak, and it speaks back.

The part I’m proudest of is a contract, not a feature: when a translation fails, Passage raises an honest error instead of echoing your source text back disguised as output. The public API is signed, rate-limited, and hardened against prompt injection — embedded instructions get translated literally, not obeyed.

Python 3.12 · NiceGUI · OpenAI + Whisper · Cloud Run, CI-gated
