01 — AI research terminal · Flagship

finplatform. Research that tells you the truth.

My AI research terminal. Screen stocks, read options clearly, dig into private companies, and pressure-test an idea before you put money behind it.

5→1five apps merged into one terminal
local → Claudeone router, your model pick honored end to end
4invariants every answer is evaluated against
1→10credits per request, priced per model, shown up front

The hard part isn’t calling a model. It’s calling the right one, at the right cost, and proving the answer is good. Every request rides a tiered router: quantized local models on my RTX 5090 through Ollama for the fast, cheap work, Claude when the question deserves frontier reasoning. You pick the model. Every feature honors the pick, and the interface tells you which model answered and what it cost.

The stack is boring where it should be and sharp where it counts. A Python backend on the standard library, a React + Vite front end, Supabase auth with server-side JWT verification. The screener is metric-driven, so one new metric definition buys a filter, a sort, and a column for free. The options panel turns a live chain into plain-English odds. The private-company pipeline scrapes, extracts, and draws a market map.

Then the part I care about most: evaluation. LLMs lie confidently, so every answer is held to four invariants. No fabrication. No obeying injected instructions. Honest caveats. Abstain when the data isn’t there. Real usage becomes traces, failures become new eval cases, and CI runs the suite before anything ships. Inference optimization, model routing, evals, CI/CD: the same skills that run production payments, pointed at a product I own.

Honest verdict

I built a swing-trade signal engine for it and tested it hard. The verdict was no real edge. finplatform says that to your face. I’d rather ship the truth than a demo that flatters you.

Python · React + Vite · Ollama on RTX 5090 · Claude API · Supabase · GitHub Actions

02 — Translation workspace

Passage. Translation that shows its work.

Translate text, documents, photos, and voice. A human stays in the loop the whole way through.

96.86%cheaper than the agency quote it replaced
57tests that must pass before any deploy
4ways in: type it, drop it, photograph it, say it
0silent failures. It raises, it never fakes.

Most translation tools hand you a wall of text and hope. Passage shows every segment next to its source so you can check the work, fix one line, and keep moving. Photograph a street sign and it paints the translation back onto the image. Speak to it and it speaks back.

My favorite part is a rule, not a feature. When a translation fails, Passage tells you. It will never echo your source text back and call it done. The public API is token-signed and rate-limited, prompt injection gets translated instead of obeyed, and every push runs the full test suite in GitHub Actions before Cloud Run sees it.

Python 3.12 · NiceGUI · OpenAI + Whisper · GitHub Actions → Cloud Run
