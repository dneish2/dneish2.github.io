Codex and Claude Code, on the same work

Two coding agents, the same repository, the same tasks. Not a benchmark. A record of where each one earned its keep and where it cost me an afternoon.

David Neish Outline · in progress

The outline ships before the prose does. These are the sections, and the measurements each one needs, so you can hold the finished piece to them.

What the comparison actually is

Both agents get run against work I was going to do anyway, in repositories that already exist, with tests that already pass or fail for real reasons. No toy tasks. The unit of comparison is a task I finished, not a score.

Where each one is genuinely better

The interesting answer is probably not "one wins." It is which kinds of task each is suited to: long multi-file refactors, a bug with a known reproduction, greenfield code with no tests to lean on, and work where the hard part is reading rather than writing.

The failure modes are the story

Confident wrong answers, silently narrowed scope, tests written to pass rather than to check. These are the costs that do not show up in a demo, and they are the reason the piece exists.

What it costs

Tokens, wall-clock, and my attention, which is the expensive one. An agent that takes twenty minutes unattended beats one that takes five and needs watching.

How I will avoid fooling myself

One run is not a result. Anything model-dependent gets repeated, the tasks are fixed before either agent sees them, and where the finding does not replicate, the piece says so.
